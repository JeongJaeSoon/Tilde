# Tilde 1.1.1

A small maintenance release with two fixes.

## Fixes

- **Line endings in mixed files.** When a file mixes line endings — say, a CRLF file that a script or an agent appended a few LF lines to — saving used to rewrite every line to the most common style, so changing one line could show up as a stray change on lines you never touched in `git diff`. Now only new and edited lines take the file's usual ending; every other line keeps its own, and a save without edits leaves the file byte for byte as it was. Files with a single line-ending style save exactly as before. (#17)
- **The caret around Markdown headings.** On a heading line, the caret now spans the heading's text instead of a short body-height sliver pinned to the top of the line. On the last line of a document that ends with a heading, it sits one line below the heading instead of inside it. (#21)

## Install

1. Download `Tilde-v1.1.1.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.
