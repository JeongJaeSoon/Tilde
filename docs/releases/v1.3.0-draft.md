# Tilde 1.3.0

Tab follows each file's indentation, invisible characters get a faint mark, and ⌘-click opens Markdown links in the editor.

## New

- **Tab follows the file's indentation.** When a file opens, Tilde looks at how it's already indented. In a file indented with spaces, Tab inserts spaces up to the next indent stop. In a tab-indented file, or one with no indented lines yet, Tab inserts a tab as before. YAML files always get spaces: the file's own width, or 2. With several lines selected, Tab indents each of them and leaves empty lines empty. ⇧Tab outdents the current line or every selected line. Each Tab or ⇧Tab is one ⌘Z. (#18)
- **Invisible characters are visible.** Characters that draw as nothing or look just like a space now get a faint mark in the editor: zero-width spaces, a stray byte-order mark, bidirectional controls, and no-break and full-width spaces. Control codes such as NUL and ESC show as ␀ and ␛. A line with bidirectional controls reads in the order it's stored, so they can't disguise what the text says. The marks are drawn only: saving, copying, and Find still see the original characters. (#19)
- **⌘-click opens Markdown links in the editor.** With Markdown Styling on, ⌘-click a `[text](url)` link to follow it the way Reader does. A `#heading` link scrolls to that heading. A link to a local file opens it in its own window, when macOS grants access to the file. A web link opens in your browser. The pointer turns into a hand while ⌘ is held over a link, and a plain click still just places the caret. (#14)

## Install

Already on Tilde 1.2.0 or later? Choose **Tilde ▸ Check for Updates…**. If you installed with Homebrew, run `brew upgrade --cask tilde`.

For a new install:

1. Download `Tilde-v1.3.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Known issue: in the editor, ⌘-click on a link whose URL contains parentheses, like `[Foo](https://en.wikipedia.org/wiki/Foo_(bar))`, opens the address cut off at the first `)`, and badge links such as `[![CI](…)](…)` don't respond to ⌘-click. Reader follows both correctly (#38).
