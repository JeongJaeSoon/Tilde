# Tilde 1.2.1

Reader shows task lists as checkboxes, and text files with no extension open in Tilde.

## New

- **Task lists in Reader.** A list item that starts with `[ ]` or `[x]` shows an empty or checked box in place of its bullet or number, in any list and at any depth. Checked items are dimmed, with no strikethrough. The boxes are read-only: edit `[ ]` and `[x]` in the editor, where they now dim like list markers. (#12)

## Fixes

- **Files with no extension.** SSH keys (`id_ed25519`, `id_ed25519.pub`), `Dockerfile`, `.gitignore`, `.env`, and other text files whose names macOS doesn't recognize as text now open in Tilde from Open With and File ▸ Open. They open as plain text, and ⌘S saves them in place under the same name and permissions. Tilde doesn't become the default app for them. An image, a PDF, or another binary file picked this way is refused with a short alert. (#29)

## Install

Already on Tilde 1.2.0? Choose **Tilde ▸ Check for Updates…**. If you installed with Homebrew, run `brew upgrade --cask tilde`.

For a new install:

1. Download `Tilde-v1.2.1.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Known issue: Save As and Duplicate suggest a name ending in `.txt` for these files, as they already do for `.json` and other types Tilde doesn't save natively (#39).
