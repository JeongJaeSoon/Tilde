# Tilde 1.0.1

A small maintenance release with one editor fix.

## Fixes

- The insertion caret on the last line of a document is no longer taller than the others. On an empty document, or any document that ends with a newline, the final line's caret now matches the text height of every other line instead of standing 1.5× tall.

## Install

1. Download `Tilde-v1.0.1.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.
