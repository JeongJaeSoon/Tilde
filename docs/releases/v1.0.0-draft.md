# Tilde 1.0.0

The first public release of Tilde — a tiny, beautiful text editor for macOS.

Tilde is made for opening a single text or Markdown file, reading it comfortably, making a small edit, and getting out of the way.

## Highlights

- Native macOS document-based editing for `.txt`, `.md`, and `.markdown` files
- Lightweight Markdown styling that keeps the original syntax visible
- Reader mode for fully rendered, read-only Markdown
- Quiet syntax highlighting for JSON, YAML, and TOML configuration files
- UTF-aware text handling with encoding and line-ending preservation
- Standard macOS editing features: undo, Find & Replace, spell check, autosave, Versions, and tabs
- Light, Dark, and System appearance
- English, Korean, Japanese, and Simplified Chinese interface
- Apple Silicon and Intel support in one universal app
- Local-only processing with no account, cloud storage, analytics, or AI features

## Install

1. Download `Tilde-v1.0.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Tilde is intentionally a focused document editor, not an IDE, project workspace, note database, or Markdown authoring suite.
