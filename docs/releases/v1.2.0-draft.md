# Tilde 1.2.0

Tilde can now update itself.

## New

- **Check for Updates…** sits in the Tilde menu, right below About Tilde. Choose it and Tilde looks for a newer version and shows what changed. If you choose Install Update, it downloads the new version, checks its signature, replaces itself, and relaunches. Tilde checks only when you ask. Nothing runs at launch or in the background. (#27)

## Getting this version

Tilde 1.1.1 and earlier can't update themselves, so get this version the usual way one last time:

- download the DMG below, or
- run `brew upgrade --cask tilde` if you installed with Homebrew.

From the next release on, Check for Updates… does it for you.

## Install

1. Download `Tilde-v1.2.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

This release is for the version downloaded from GitHub or installed with Homebrew. The App Store version stays at 1.1.1 and has no Check for Updates…, because the App Store keeps it up to date.

Checking for updates connects to GitHub, only when you choose it. See the [privacy policy](https://github.com/heyeuca/Tilde/blob/main/PRIVACY.md).

In-app updates use [Sparkle](https://sparkle-project.org).
