# Tilde 1.0.2

A small maintenance release with one editor fix.

## Fixes

- The insertion caret on the last line of a document now stays put. It used to sit at a different height depending on how you got there — a little too low right after pressing Return, on the line while you typed, and hugging the line above once you deleted back to an empty line, with the same drift after a blank line or on an empty document. The caret now sits exactly where the text you type will appear, at text height, in every case. (#7)

## Install

1. Download `Tilde-v1.0.2.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.
